# 💬 Real-Time Web Chat App

A WhatsApp-style real-time chat application built using Flask and Socket.IO.

---

## 🚀 Features

- 🔐 User authentication (login/signup)
- 💬 Real-time messaging (no page reload)
- 📩 Persistent chat history (stored in database)
- 🎨 Clean modern UI
- ⚡ Fast and lightweight

---

## 🛠 Tech Stack

- Backend: Flask, Flask-SocketIO
- Frontend: HTML, CSS, JavaScript
- Database: SQLite


---

## ⚙️ Setup Instructions

```bash
git clone https://github.com/your-username/Web_Chat_App.git

Create .env file:
SECRET_KEY=your-secret-key
